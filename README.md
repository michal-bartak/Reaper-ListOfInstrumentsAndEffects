# <img src="icon/instruments-effects-128.png" width="30" align="top" alt=""> List of Instruments and Effects

A REAPER script that lists every plugin an active project uses, grouped into
instruments, effects, input FX, monitoring, and offline/inactive, and copies the
report to the clipboard as plain text, Markdown or BBCode. Written for the KVR
One Synth Challenge, which asks for the technical details of a production.

## Install

Via ReaPack. Import this repository once, under *Extensions → ReaPack → Import
repositories*:

```
https://github.com/michal-bartak/ReaPack/raw/main/index.xml
```

Then *Browse packages* and install **List of Instruments and Effects**. Read
[Installation](https://michal-bartak.github.io/Reaper-ListOfInstrumentsAndEffects/installation/)
for further details.
