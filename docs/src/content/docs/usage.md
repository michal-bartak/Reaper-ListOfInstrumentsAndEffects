Run the action. The window opens and shows the report.

## Copy to clipboard

Four buttons copy the report to the clipboard:

| Button | Format |
| --- | --- |
| Plain Text | The text shown in the window |
| Markdown | Tables in Markdown syntax |
| BB Plain | BBCode, with bold headings |
| BB Code | Plain text wrapped in `[CODE]` tags |

See [Export formats](/ListOfInstrumentsAndEffects/formats/) for what each one
looks like.

## Debug

The window normally shows plain text, whichever format you copy. Tick **Debug**
to show exactly what went to the clipboard.

## About

The ⓘ button at the right of the button row opens a dialog. It shows the
version you are running, the author, the licence, and links to this site and
the repository.

The window behind it dims while the dialog is open. Close the dialog with its
Close button, with Escape, or by clicking outside it.

## Refreshing

The report refreshes itself when you edit the project or switch project tab.
Pressing a Copy button also refreshes it.

## The preview

The preview is read-only. You can select text in it and scroll it. Resize the
window to make it larger.
